# TimeLedge app icon

`TimeLedge-1024.png` is original artwork created for this project. It depicts a
blue clock resting on a precise horizontal ledge and contains no third-party
logo, text, or copied product artwork.

Run `./script/generate_app_icon.sh` on macOS to regenerate
`Resources/TimeLedge.icns` from the 1024 px master.
